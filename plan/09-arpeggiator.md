# 09 — Arpeggiator

## 1. Parameters
| Key | Range | Notes |
|---|---|---|
| `arp_on` | enum `Off, On` | When on, note events go to the arp instead of the allocator |
| `arp_mode` | enum `Up, Down, UpDown, UpDown2, Played, Random, Chord` | Append-only. `UpDown` repeats the end notes; `UpDown2` does not. |
| `arp_oct` | int 1..4 | Octave range |
| `arp_rhy` | int 0..32 | Rhythm pattern; 0 = every step (§3) |
| `arp_rate` | enum `1/4, 1/8D, 1/8, 1/8T, 1/16D, 1/16, 1/16T, 1/32, 1/32T` | Default `1/16` |
| `arp_gate` | 0..1 | Gate length 5 %…100 % of the step (1.0 = legato/tie) |
| `arp_swing` | 0..1 | Delays even 16th-grid steps: 50 % (straight) … 75 % |
| `arp_latch` | enum `Off, On` | Keeps playing after keys are released |
| `arp_ksync` | enum `Off, On` | Restart the pattern on the first note of a new chord |
| `arp_vel` | enum `Played, Fixed` | Fixed = 100 |
| `arp_scale` | enum `Off, Set, Maj, Min, Dor, Phr, Lyd, Mix, Pent, MPen, Blue` | Append-only. `Set` follows the Move set's root and scale (C minor when there is no set info, as in the browser); the fixed scales are in C |

## 2. Note ordering
- **Held set.** Up to 16 notes. They are kept in insertion order (for `Played`) and as a sorted copy (for the other modes).
- **Scale.** With `arp_scale` on, each held key moves to the nearest scale note at or below it (above it only at the bottom of the MIDI range). Keys that land on the same note play once. A change of scale or set applies on the next step; what you hold is unchanged, so turning it off restores the keys.
- **Octave expansion.** The sequence spans `arp_oct` octaves: it is the pattern over notes and octaves (e.g. Up over C E G with 2 octaves: C E G C' E' G').
- **`Random`.** Picks uniformly from the expanded set without immediate repeats when the set has more than one note.
- **`Chord`.** Plays all held notes, in all octaves (up to 8 voices), on each active step.
- **Changing the held set** (adding or removing notes) never resets the step position unless `arp_ksync` is on and all keys were released before.

**Latch.**
- With `arp_latch = On`, releasing all keys keeps the set playing.
- The first note-on after a full release replaces the set.
- Further notes held at the same time add to it.
- Turning latch off releases the set.

## 3. Rhythm patterns
- **Format.** Pattern 0 is all 16 steps on. Patterns 1–32 are **original** 16-step patterns generated by `tools/rhythms/rhythms.py`, each as `{uint16 on_mask, uint16 tie_mask, uint8 length}`. Length is 1..16 steps; the pattern loops.
- **Content.** Euclidean rhythms E(k, n) for musically useful k/n (3/8, 5/8, 7/16, 5/16, 9/16, …), plus hand-designed syncopations, 2- and 3-step offbeats, and tie patterns (tie = extend the previous note through this step).
- **Generation.** Names for display come from the generator (e.g. `E5:16`, `Off3`, `Tie1`) and go into `params_gen.c` as `const` data.
- **Rests.** A step that is off is a rest, and the note order does not advance. **VERIFY** this by ear. The alternative is to advance on rests too, which gives a different musical feel; make it a compile-time switch until decided.

## 4. Clocking
`step_beats` comes from `arp_rate`, e.g. 1/16 = 0.25 beats.

**Synced (host running).** When `get_clock_status() == RUNNING` and `get_beat_position()` ≥ 0:
- Estimate the beat position at each sub-block start: `beat = beat0 + sb·bpm/(60·fs)`, where `beat0` is read once per block.
- A step fires when `floor((beat − swing_offset(step)) / step_beats)` increments.
- On transport start (`STOPPED → RUNNING`) the arp re-aligns step 0 to the bar.

**Free (stopped or unavailable).** An internal phase accumulator runs at `host->get_bpm()` (120 if 0 or unavailable). The first note-on starts immediately at step 0.

**Swing.** Even-numbered steps on the 1/16 grid are delayed by `(swing − 0.5)·step_len`. The swing range 0..1 maps to 50 %…75 %.

**Gate.** A note-off is scheduled at `gate·step_len`, at sub-block resolution (0.36 ms). Tied steps cancel the pending note-off and retrigger nothing.

**Output.** Generated notes go to the normal voice allocator. Voice modes, unison and glide all apply.

## 5. State & UI
- **State.** The arp position is not stored in `state`; parameters are.
- **Panic.** On preset load or `arp_on → Off`, the arp sends note-offs for all its notes.

The UI page layout is in [12 §3](12-ui-pages.md).

## 6. Tests
- **Timing.** With a simulated clock at 120 BPM, 1/16, Up over C E G and 1 octave, the onsets fall every 5512.5 samples ±16 in this order: C E G C…
- **Modes.**
  - `UpDown` vs `UpDown2` sequences over C E G: `C E G G E C …` vs `C E G E C E …`.
  - `Chord` triggers 3 voices per step.
- **Rhythms and gate.** Rhythm masks skip the correct steps, ties extend notes, and the gate at 0.5 gives a note length of 50 % ± 1 sub-block.
- **Latch.** Releasing keys keeps the arp playing, and a new chord replaces the set.
