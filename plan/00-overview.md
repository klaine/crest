# 00 — Overview & Requirements

## 1. Product statement
Crest brings the architecture and playing feel of a modern hybrid polysynth to Ableton Move. That architecture is the Peak's:
- 3 oscillators, each with a shape control
- a hot analog-style multimode filter with three drive stages
- 3 envelopes and 4 LFOs
- a two-source modulation matrix
- Animate buttons and macros
- an arpeggiator
- a studio FX chain

Crest runs entirely inside Move as a Schwung chain sound generator, and every page is editable with Move's 8 encoders.

## 2. Goals
1. **Sound.** Fat, clean, low-alias oscillators. The filter should sing and growl when driven. Polyphonic pads must stay stable with 8 voices and all FX on.
2. **Full feature set in v1.0.** Every section listed in §4 is implemented and reachable from the Move UI.
3. **Realtime-safe and frugal.** The worst-case patch uses at most 900 µs of each 2.9 ms block on core 3; see [03 §8](03-dsp-architecture.md).
4. **Move-native UX.** Pages fit the 2×4 encoder grid, a Main page holds the 8 most useful knobs, and every key can be automated, used in Scenes and modulated by chain LFOs.
5. **Robust state.** Patches survive Set reloads, "My Presets" and version upgrades.
6. **Fast iteration.** Codegen keeps the C tables, UI contract and presets in sync. Native, golden and WASM builds allow testing without a device.

## 3. Non-goals (v1)
- Sample-accurate emulation of any hardware unit, and import of hardware patch files.
- User wavetable import (deferred to v1.x; it needs a non-RT worker thread).
- A custom `ui_chain.js` for on-device UI. The host knob grid is used; see [12](12-ui-pages.md).
- MPE beyond polyphonic aftertouch and pitch bend.
- Multitimbral operation (one patch per instance; Move gives one instance per track).

## 5. Naming & IP rules
- **Name and wording.** The module is "Crest". Descriptions may say "inspired by classic hybrid polysynths" in user-facing text. They must not use the Novation or Peak trademarks, logos or panel graphics in the module, presets, help or release notes; the "Peak" name appears only in these internal planning docs.
- **Original content.** Wavetables, arp rhythm patterns and factory presets are original works generated by our own tools. Nothing is copied from hardware dumps or manuals.
- **Licence.** Crest uses the MIT licence (same as the siblings), with a `LICENSE` file in the package.
