# Contributing to Crest

Bug reports, patch ideas and pull requests are welcome. For anything bigger than a small fix, open an
issue first so we can agree on the approach.

- **Branch:** fork, branch from `main`, and open the pull request against `main`. Don't touch the
  `pages` branch: it's generated by `scripts/pages.sh` and replaced on every publish.
- **Build and test:** `scripts/build.sh` runs the generator check, the contract, UI and native tests
  (about 10,500 of them), then builds `dsp.so` and the package. It needs [zig](https://ziglang.org) and
  Python 3. The web synth is `scripts/build_web.sh`. Run both before you open a pull request.
- **Generated files:** `tools/gen/params.py` drives `gen.py`, which writes the parameter tables,
  contract, factory presets and UI JSON. Never edit those by hand: change `params.py`, then run
  `scripts/build.sh --gen`. The build fails if anything is stale.
- **Spec:** `plan/` is the spec, and once code exists the code is the source of truth. If they
  disagree, fix one of them in the same pull request, and update `plan/17-implementation-status.md`
  when what's built changes.
- **Peak import:** there are two converters, the Python one in `tools/peak/` and the C twin in
  `src/dsp/peak_import.c`. They must agree (`tests/peak/test_import.py` checks), so change both.
- **Realtime:** no allocation or file I/O on the audio thread.
- **Third-party material stays out of git.** Novation's manual and banks (`reference_novation/`) and
  imported Peak banks (`presets/peak/`) are git-ignored for licensing reasons. No Peak patch or
  Novation material may reach a committed file or a release package. Contributed patches and
  wavetables must be your own work or freely licensed.
- **Style:** match the surrounding code, keep `-Wall -Wextra -Werror` clean, and keep commits focused.

By contributing you agree your work is released under the repository's [LICENSE](LICENSE).
