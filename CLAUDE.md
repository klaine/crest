# Crest: agent notes

Peak-inspired 8-voice `sound_generator` (Schwung API v2), module id `crest`. Read
[README.md](README.md) for the product, and [plan/README.md](plan/README.md) for the spec. This file
covers working on the code.

## Commands

```sh
scripts/build.sh              # gen --check, contract, Peak import, UI and ~10,500 native tests, dsp.so, check_so.py, package, build/crest.html
scripts/build.sh --gen        # regenerate first (after editing tools/gen/params.py or presets)
scripts/build.sh --render     # also one WAV per factory patch in build/demo
scripts/build.sh --release    # a publishable package: no local Peak banks, checked by scripts/check_release.py
scripts/build_web.sh          # crest.wasm + build/site (python3 -m http.server -d build/site 8765) + build/crest.html
scripts/build_web.sh --single # only build/crest.html: the shareable single file, without the Peak banks
scripts/pages.sh [--push]     # build/crest.html as index.html on the `pages` branch (build.sh runs it, without --push)
scripts/deploy.sh [host]      # staged install on a Move; scripts/logs.sh follows the debug log
```

## Spec and status

- `plan/` is the spec, and the code is the source of truth once it exists. If they disagree, fix one
  of them in the same change. `plan/17-implementation-status.md` records what's built, measured and
  different from the spec: update it when that changes.
- **VERIFY** in `plan/` marks assumptions about the device or host. Crest runs on a Move, Peak `.syx`
  import included, but the individual VERIFY items haven't been ticked off (`plan/16` lists the risks).

## Generated files (don't hand-edit)

- `tools/gen/params.py` drives `gen.py`, which writes `src/dsp/params_gen.*`, `contract_gen.c`,
  `factory_presets.c`, `build/ui/*.json` and the GENERATED META blocks in `src/cards.js` and
  `src/canvas.js`. The build runs `gen.py --check` and **fails if anything is stale**.
- The committed files only ever hold the Crest patches. When `presets/peak/` has banks, `gen.py` also
  writes `factory_presets.c`, `contract_gen.c` and `canvas.js` with them to `build/peak/`, and
  `build/*.json` to match. `build.sh` and `build_web.sh` compile and package those in place of
  `src/`'s, so local builds carry the Peak banks and nothing committed does.
- `gen.py --no-peak` writes the bank-dependent files (`factory_presets.c`, `contract_gen.c`,
  `ui_*.json`) without the Peak banks to `build/web/`, for the single file. `scripts/build_single.py`
  folds that wasm, `web/` and `src/web/` into `build/crest.html`, and fails if a Peak patch name or a
  build path would ship. It rewrites `app.js`'s `here` and the UI's `./x.js` imports, which
  `web/embed.js` serves as `crest:/` URLs: keep those patterns, or update the script.
- `src/dsp/wavetables.c` comes from `tools/wavegen/wavegen.py`; `src/dsp/rhythms_gen.h` from
  `tools/rhythms/rhythms.py`.
- `presets/peak/*.json` come from `tools/peak/import_banks.py` and `level.py` (pipeline in
  `plan/18`). `presets/factory/` holds the curated patches.

## Rules

- **Flags:** `-Wall -Wextra -Werror -Wshadow -Wdouble-promotion`, and `-ffast-math
  -fno-finite-math-only` on device and in tests alike (the NaN guard in `render_block` depends on
  it). Native tests run under UBSan.
- **Peak import has two converters:** the Python one (`tools/peak/`) and the C twin
  (`src/dsp/peak_import.c`, used by the browser and the Move). `tests/peak/test_import.py` requires
  them to agree. Change both together.
- **Third-party material:** `reference_novation/` (Novation's manual and banks) is git-ignored and
  stays local. `presets/peak/` has unclear redistribution rights (see the README): it and
  `build/peak/` are git-ignored, and no Peak patch may reach a committed file (check
  `src/dsp/factory_presets.c` and `src/canvas.js` before committing). Local `dsp.so` and `build/site`
  include them, `build/crest.html` (the file meant for sharing) never does. A package for a release
  is built with `scripts/build.sh --release`, never from a normal local build.
- **`pages` branch:** generated by `scripts/pages.sh`, one parentless commit with `index.html` and
  `.nojekyll`, replaced on each change and force-pushed. Never commit to it by hand or merge it.
- Realtime: the audio thread does no I/O and no allocation. The Peak bank loader is a worker thread
  (`src/dsp/peak_bank.c`, the reason for `-lpthread`).
- Effects were adapted from Amino's `src/dsp/fx.c`: a fix here may apply there too.
